# ⛰ トレイルランニング（2D横スクロールゲーム）

体力とスピードを管理しながら高い山を駆け抜ける、横スクロール型のトレイルランニングゲームです。
プレーヤーは画面左に固定され、コースの地形（急登・谷・ガケなど）が右から流れてきます。
標高が上がると地面が草原→岩場→雪へ、背景も樹林帯→岩稜帯→雲海と空へと移り変わります。全5コース。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。

ローカルサーバーで開く場合:

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## 操作方法

| キー | 操作 |
|---|---|
| `スペース` | ジャンプ |
| `Shift`（押しっぱなし） | スピードアップ（離すと減速）。**登りではスピードが上がりにくく、下りではすぐ上がります** |
| `←` `→`（または `1`〜`4`） | 補給食の選択（タイトル画面ではコース選択） |
| `E` | エネルギー補給（選択中の補給食を食べる） |
| `R` | リスタート |
| `T` | タイトル（コース選択）へ戻る |

## ゲームの仕組み

### 体力とスピード
- 歩いている（最低スピード）だけでも体力は**僅かに**減っていきます。
- **スピードを上げるほど体力の減りが速くなります**（走行分の消費は速度の2乗に比例）。
- 同じスピードでも地形によって消費が変わります: **上り坂 > 平地 > 下り坂**。
- さらに**登りで走ると勾配に応じた非常に大きな追加ペナルティ**がかかります（急登をShift全開で登ると約8/秒、10秒ちょっとで体力が尽きるペース。「⚠オーバーペース！」警告が出ます）。登りまでずっとShiftを押し続ける走りでは補給が追いつかず完走できません。**登りを我慢して、平地と下りで飛ばすコントロールが最速**です。
- スピードの上がり方も地形に依存します。Shiftを押しっぱなしにしても、急登ではなかなか上がらず、平地ではそれなりに、下りでは一気に上がります。
- **登りに入ると勾配に応じて強制的に減速**します。ただしShiftを押し続けていれば、勾配ごとの上限スピード（最急勾配で45）までは維持できます。登りの岩はスピードを維持したままジャンプで越えるのがコツです。
- 体力が **60を下回ると最大スピードがどんどん低下**します（体力45で最大81、30で63、15で44）。疲れてからでは飛ばせないので、飛ばすなら体力のあるうちに。
- 体力が **35を下回っている間は「回復上限」がどんどん下がり**、補給しても満タンまでは戻らなくなります（下限45）。赤字ペースを続けるほど後半バテて走れなくなります。
- エネルギー補給には**クールダウン(2.5秒)**があり、連続で食べ続けて赤字ペースを支えることはできません。

### 補給
- コース上のジャンプで届く高さに**補給食**（飴・バナナ・ドリンク・おにぎり）が浮いています。取ると持ち物に追加され、`E`キーで食べると回復します。
- 補給食の回復量: 飴 +8 ＜ バナナ +18 ＜ ドリンク +30 ＜ おにぎり +45
- 回復量が大きいものほど取りにくくなっています。飴とバナナはその場に浮いているだけですが、**ドリンクとおにぎりは円を描いて回っており**（点線が軌道）、タイミングを合わせてジャンプしないと取れません。おにぎりの軌道が一番大きく速い上に、取得判定もシビアです。
- 持ち物の一覧は画面左上に表示されます。
- 初期装備: 飴×2、バナナ×2

### 障害物
ジャンプで飛び越えないと体力が大きく減ります（⚠マークが目印）。
岩とガケは歩行スピードのジャンプでも完璧なタイミングならギリギリ越えられます。川は幅が広いので、スピードに乗って跳ぶ必要があります:

| 障害物 | ダメージ |
|---|---|
| 木の根 | -8 |
| 岩場 | -15 |
| 川 | -25 |
| ガケ | -35 |

### エネミー・ギミック
| 出現コース | ギミック | 効果 |
|---|---|---|
| 2以降 | 🐝 蜂 | 空中を上下に飛んでいる。触れると -12。補給食の近くにいることが多く、タイミングをずらしてジャンプする必要がある |
| 3以降 | 泥道 | 接地中はスピードが上がらず体力消費も増える。ジャンプで飛び越えられる |
| 4以降 | 落石 | 登りの途中で前方から岩が転がってくる（⚠落石！の警告）。ジャンプでかわす。当たると -20 |
| 5 | 強風 | 突風が吹いている間は前に進みにくく、体力消費も増える |

### コース一覧（全コース 2100m）
1. **ふたつのピーク** … 山頂を2つ越えるスタンダードな高山コース
2. **尾根の縦走路** … 蜂が飛び交う小刻みなアップダウンの稜線
3. **泥の森** … 泥道と木の根だらけの低山の森
4. **岩壁の大登攀** … 標高1660の大岩壁。登りでは落石が転がってくる
5. **嵐の大縦走** … 強風・泥・落石・蜂、全部入りの最難関

### ゴールとタイム記録
- 川は登りには現れず、下り坂や谷にだけ現れます。
- 走行タイムは画面上部中央に表示されます。
- ゴールタイムの**ベスト5**がコースごとに自動で記録され、タイトル画面とゴール画面に表示されます（ブラウザのlocalStorageに保存。同じブラウザで開けば次回も残ります）。

## バランス調整

ゲームバランスのパラメーターは `index.html` 冒頭の `CONF`・`BEE`・`MUD`・`BOULDER`・`WIND` にまとまっています。
各コースの地形・障害物・アイテム・ギミック配置は `COURSES` 配列で定義されています。
