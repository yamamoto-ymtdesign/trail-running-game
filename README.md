# ⛰ トレイルランニング（2D横スクロールゲーム）

体力とスピードを管理しながら高い山を駆け抜ける、横スクロール型のトレイルランニングゲームです。
プレーヤーは画面左に固定され、コースの地形（急登・谷・ガケなど）が右から流れてきます。
標高が上がると地面が草原→岩場→雪へと変化します。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。

ローカルサーバーで開く場合:

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## 操作方法

| キー | 操作 |
|---|---|
| `スペース` | ジャンプ |
| `Shift`（押しっぱなし） | スピードアップ（離すと減速）。**登りではスピードが上がりにくく、下りではすぐ上がります** |
| `←` `→`（または `1`〜`4`） | 補給食の選択 |
| `E` | エネルギー補給（選択中の補給食を食べる） |
| `R` | リスタート |

## ゲームの仕組み

### 体力とスピード
- 歩いている（最低スピード）だけでも体力は**僅かに**減っていきます。
- **スピードを上げるほど体力の減りが速くなります**（走行分の消費は速度の2乗に比例）。
- 同じスピードでも地形によって消費が変わります: **上り坂 > 平地 > 下り坂**。
- さらに**登りで走ると追加ペナルティ**がかかります。急登の全力走は平地の3倍以上のペースで体力が溶けるので、登りは歩き、下りと平地で稼ぐのが基本です。
- スピードの上がり方も地形に依存します。Shiftを押しっぱなしにしても、急登ではなかなか上がらず、平地ではそれなりに、下りでは一気に上がります。
- 体力が **50を下回ると最大スピードが低下**していきます（疲れると元気な時のようには走れない）。
- 体力が **35を下回っている間は「回復上限」が徐々に下がり**、補給しても満タンまでは戻らなくなります（下限55）。無理をしすぎない体力管理が重要です。

### 補給
- コース上のジャンプで届く高さにアイテムが浮いています:
  - **補給食**（飴・バナナ・ドリンク・おにぎり）… 取ると持ち物に追加。`E`キーで食べると回復。
  - **栄養スナックバー** … 取った瞬間にその場で少し回復（+15）。
- 補給食の回復量: 飴 +8 ＜ バナナ +18 ＜ ドリンク +30 ＜ おにぎり +45
- 持ち物の一覧は画面左上に表示されます。
- 初期装備: 飴×2、バナナ×2

### 障害物
ジャンプで飛び越えないと体力が大きく減ります（⚠マークが目印）:

| 障害物 | ダメージ |
|---|---|
| 岩場 | -15 |
| 川 | -25 |
| ガケ | -35 |

### ゴールとタイム記録
- コース1は全長 **2100m**、最高標高132（2つのピークを越える高山コース）。体力が尽きる前にゴールを目指してください。
- 川は登りには現れず、下り坂や谷にだけ現れます。
- 走行タイムは画面上部中央に表示されます。
- ゴールタイムの**ベスト5**が自動で記録され、タイトル画面とゴール画面に表示されます（ブラウザのlocalStorageに保存。同じブラウザで開けば次回も残ります）。

## バランス調整

ゲームバランスのパラメーターは `index.html` 冒頭の `CONF` オブジェクトにまとまっています。
コースの地形は `SEGMENTS`、障害物は `HAZARDS`、アイテム配置は `PICKUPS` で定義されています。
